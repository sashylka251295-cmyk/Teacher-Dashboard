# Local image gallery

Add public, non-sensitive JPG, PNG or WebP files to one of these folders:

- `course-covers/` for course covers;
- `unit-covers/` for unit covers;
- `student-avatars/` for reusable illustrated avatars.

Then add an object with a human-readable `label` and the public relative `path` to the matching array in `manifest.json`. File names must contain only Latin letters, numbers, dots, underscores and hyphens.

These files are shipped with the public website. Never put private student photos or confidential material here.
