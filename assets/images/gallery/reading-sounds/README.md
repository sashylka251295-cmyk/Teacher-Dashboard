# Reading sound illustrations

Place reusable, non-sensitive phonics illustrations in this folder as PNG, JPG or WebP files.

Then register each file in `../manifest.json` under `readingSounds`, for example:

```json
{
  "label": "Ship — sh",
  "path": "./assets/images/gallery/reading-sounds/ship-sh.png"
}
```

The image remains a public decorative GitHub Pages asset. Student names, photos and private lesson materials must not be stored here.
